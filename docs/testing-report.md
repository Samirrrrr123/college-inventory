Проверены пустые данные, ошибка и повтор, график, RU/EN, темы, обновление и перезагрузка, ширины 360/768/1440/1920 px. Общий браузерный прогон выполняется в CI.

## Что проверяется

| Часть                 | Основные проверки                                                                |
| --------------------- | -------------------------------------------------------------------------------- |
| Вход                  | Регистрация, пароль, access/refresh, выход, восстановление и отзыв сессий        |
| Права                 | Роли на сервере, блокировка, запрет доступа к чужим заявкам                      |
| Каталог               | Создание, изменение, удаление, поиск, фильтры, сортировка и страницы             |
| Выдачи                | Рассмотрение заявки, выдача всего комплекта, возврат, отказ при занятом предмете |
| Одновременные запросы | Две попытки выдачи или возврата дают только один успех                           |
| Файлы                 | Тип, размер до 5 МБ, безопасное имя, точность скачанных байтов, права и удаление |
| Интерфейс             | Валидация форм, ошибки API, подтверждение удаления, RU/EN и темы                 |
| Экран                 | Ширины 360, 768, 1440 и 1920 px                                                  |

Инвентаризация проверена отдельно: состав аудитории фиксируется при начале; отметки сохраняются после перезагрузки. Без всех отметок завершение запрещено, после завершения результат нельзя менять. Две одновременные попытки завершения дают один успех. Преподавателю раздел и API недоступны.

Наличие кнопок в демоверсии не считается проверкой серверных функций.

В админке проверены смена ролей, блокировка, разблокировка и отзыв старых сессий. Преподаватель и лаборант не получают список пользователей. Последний активный администратор защищён, в том числе при одновременных изменениях. Изменение сохраняется вместе с записью аудита.

## Найденные и исправленные ошибки

- Изменение имени пользователя скрывало его историю. История теперь связана с ID.
- PATCH мог сбросить поля, которых не было в запросе. Для него выделена отдельная схема.
- Удаление связанных записей иногда возвращало 500 на PostgreSQL 18. Исправлено отдельной миграцией; теперь возвращается 409.
- За прокси лимит входа считался по общему адресу. Указано нужное число доверенных прокси и добавлен тест.
- У части маршрутов Swagger повторялся префикс `/api`. Пути исправлены, добавлен тест адресов.

## CI и публичный сайт

GitHub Actions запускает линтер, форматирование, типы, тесты, сборку и Docker Compose. Полный набор браузерных сценариев работает в задании Backend с `RUN_API_TESTS=1`. При обычном запуске без API эти сценарии пропускаются.

В PR #34 прошли [проверки интерфейса](https://github.com/Samirrrrr123/college-inventory/actions/runs/39635228734) и [проверки сервера](https://github.com/Samirrrrr123/college-inventory/actions/runs/39635228732). В полном прогоне с API прошёл 21 браузерный сценарий.

На HTTPS-сайте проверены вход, восстановление сессии после перезагрузки, создание и удаление категории. Также проверен полный цикл заявки преподавателя, одобрения, выдачи двух предметов и возврата. Данные сохраняются, техника снова становится доступной. Мобильная ширина 360 px проверена; ошибок JavaScript не было.

## Как повторить

В папке frontend: `pnpm lint`, `pnpm format:check`, `pnpm typecheck`, `pnpm test`, `pnpm build`. Для браузера — `pnpm test:e2e`; нужен установленный Chromium Playwright.

В папке backend: те же проверки и `pnpm test` с отдельной тестовой БД после применения миграций. Для полного браузерного прогона запустить API и задать `RUN_API_TESTS=1` и `SEED_PASSWORD`. Настоящие пароли и .env в репозиторий не добавляются.
