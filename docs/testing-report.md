# Проверки проекта

Результаты проверенной версии от 21.10.2026. Серверные тесты используют отдельную PostgreSQL, браузерные сценарии работают с настоящим API.

| Проверка                              | Результат                  |
| ------------------------------------- | -------------------------- |
| Серверные тесты                       | 92 прошли                  |
| Тесты интерфейса                      | 50 прошли                  |
| Браузерные сценарии                   | 21 прошёл                  |
| Покрытие строк сервисов               | 97,3%, минимум задания 60% |
| Линтер, форматирование, типы и сборка | Прошли                     |

Проверены вход, роли, каталог, заявки, выдачи и возвраты, файлы, инвентаризация, пользователи, перемещения, аудит, обзор и XLSX. В том числе запрет чужих данных, занятых предметов, повторных операций и неверных файлов.

Проверены темы, RU/EN и ширины 360/768/1440/1920 px. На публичном сайте проверено сохранение данных и скачивание XLSX на двух языках. Экспорт включает все найденные записи, сохраняет ведущие нули, не выполняет формулы и отказывает при превышении 5000 строк.

Локальные запросы после прогрева на тестовых данных укладывались в 23 мс при требовании до 500 мс. Это не замер задержки публичного VPS.

## Исправленные ошибки

- История зависела от имени пользователя. Теперь используется ID.
- PATCH сбрасывал пропущенные поля. Схема изменения исправлена.
- Удаление связанной записи давало 500. Теперь возвращается отказ 409.
- За прокси неверно считались попытки входа. Настройка исправлена и проверена тестом.
- В Swagger повторялся префикс /api. Пути исправлены.

## Как повторить

В frontend: `pnpm lint`, `pnpm format:check`, `pnpm typecheck`, `pnpm test`, `pnpm build`. Браузер: `pnpm test:e2e`, нужен Chromium Playwright.

В backend: те же проверки, `pnpm test` запускается с отдельной тестовой БД после миграций. Полный браузерный прогон требует запущенный API, `RUN_API_TESTS=1` и `SEED_PASSWORD`.
