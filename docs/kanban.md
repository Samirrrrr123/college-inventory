# Задачи и канбан

Все 15 пользовательских историй заведены в [GitHub Issues](https://github.com/Samirrrrr123/college-inventory/issues). Их содержание и критерии находятся в [списке историй](user-stories.md). Наличие демо не считается выполнением fullstack-функции; такие задачи остаются открытыми. История US-15 закрыта после проверки тем, языка и адаптивности в PR #1 и #2.

Создана [доска «Инвентарь · Учебная практика»](https://github.com/users/Samirrrrr123/projects/1/views/1) с колонками Todo, In Progress и Done. Открытые истории импортированы из репозитория, US-01 отмечена In Progress. Закрытая US-15 связана с проектом, её статус Done проверен в самой задаче.

Проект пока приватный. Доступ Артёма к самой доске ещё не настроен; доступ к репозиторию у него уже есть. Критерии приёмки остаются в Issues, состояние обновляется по фактической работе. Незавершённые истории не переносить в Done только по наличию макета или интерфейса.
