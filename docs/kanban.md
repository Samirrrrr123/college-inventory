# Задачи

15 пользовательских историй находятся в [Issues](https://github.com/Samirrrrr123/college-inventory/issues). Их требования — в [списке историй](user-stories.md).

[Канбан-доска](https://github.com/users/Samirrrrr123/projects/1/views/1): Todo — предстоит, In Progress — в работе, Done — готово и проверено.

Задача считается готовой, когда работает с сервером и БД. Макет или демоверсия сами по себе её не закрывают.

Работа сохраняется в коммитах и PR каждого участника. Изменения проверяются CI; второй участник делает ревью.
