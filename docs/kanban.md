# Задачи и канбан

Все 15 пользовательских историй заведены в [GitHub Issues](https://github.com/Samirrrrr123/college-inventory/issues). Их содержание и критерии находятся в [списке историй](user-stories.md). Наличие демо не считается выполнением fullstack-функции; такие задачи остаются открытыми. История US-15 закрыта после проверки тем, языка и адаптивности в PR #1 и #2.

Сама доска GitHub Projects пока не создана: у текущего входа есть доступ к репозиторию и Issues, но нет права `project`. Это отдельное право [для API Projects](https://docs.github.com/en/issues/planning-and-tracking-with-projects/automating-your-project/using-the-api-to-manage-projects).

Для завершения настройки нужна доска с колонками Todo, In progress и Done, связанная с репозиторием `Samirrrrr123/college-inventory`. На неё нужно добавить Issues US-01–US-15, сохранить критерии приёмки и далее обновлять состояние по фактической работе. Незавершённые истории не переносить в Done только по наличию макета или интерфейса.
