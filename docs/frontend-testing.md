# Проверки frontend

Проверено локально 20.10.2026: Windows, Node.js 24, Chromium Playwright. Данные демонстрационные, backend не подключён.

| Проверка | Результат |

| Prettier | Формат соответствует конфигурации |
| TypeScript strict | Без ошибок |
| Production build | Успешно |
| Компоненты: 4 файла, 11 тестов | Все прошли |
| Браузер: 4 сценария Chromium | Все прошли |

## Компоненты

1. Поиск и фильтр оборудования, пустой список, сброс фильтров.
2. Повтор инвентарного номера: ошибка формы без её закрытия.
3. Запрет удаления оборудования, связанного с заявками или выдачами.
4. Сохранение тёмной темы и английского языка после повторного открытия.
5. Корректные настройки по умолчанию при повреждённом localStorage.
6. Отсутствие административного раздела у преподавателя и отказ при прямом открытии маршрута.
7. Преподаватель видит только свои демонстрационные заявки.
8. Вход: обязательные поля, формат email и фокус на первой ошибке.
9. Регистрация: совпадение паролей, отсутствие выбора привилегированной роли и отсутствие локального аккаунта; после корректного заполнения пароли очищаются.
10. Показ пароля и очистка при переходе между формами.
11. Восстановление: ссылка без кода не даёт отправить форму; новый пароль проходит проверку длины.

## Браузер

1. Создание оборудования, поиск, открытие карточки, закрытие через Escape с восстановлением фокуса, подтверждение удаления.
2. Тёмная тема и RU/EN сохраняются при перезагрузке; системная тема реагирует на смену цветовой схемы устройства.
3. Шесть разделов приложения и четыре формы доступа открываются без ошибок JavaScript и горизонтального переполнения на ширинах 360, 768, 1440 и 1920 px.
4. Переход со входа на регистрацию, ошибка повтора пароля, честное сообщение о неподключённом backend, очистка пароля, тёмная тема и EN на телефоне, отдельный переход к демоверсии.

Визуально проверены шесть разделов на desktop, каталог на телефоне и профиль в тёмной теме на английском. SVG-иконки из Figma загружаются без ошибок.

Дополнительно проверены формы входа, регистрации, восстановления и нового пароля на desktop и телефоне, в том числе регистрация в тёмной теме на английском. Иллюстрация с экрана входа взята из Figma и отображается в исходном размере 100 × 100 px.

## Исправленные дефекты

- Перекрытие радиокнопки системной темы иконкой мешало нажатию. Вся карточка темы теперь является областью выбора; повторный браузерный сценарий прошёл.
- Для мобильной навигации в тёмной теме подключены соответствующие иконки из макета.

## Границы проверки

Проверка маршрутов по демонстрационной роли не доказывает безопасность приложения: авторизация и доступ к данным должны отдельно проверяться на сервере.

На этом компьютере нет Docker, поэтому образ локально не собирался. В workflow `Frontend` предусмотрена отдельная сборка Docker на GitHub Actions. Статус конкретного запуска нужно смотреть в PR.

Серверные интеграционные тесты, покрытие сервисов, реальная загрузка файлов, общий Compose, публичный деплой и end-to-end работа с PostgreSQL проверяются после интеграции. Этот отчёт их не подтверждает.
