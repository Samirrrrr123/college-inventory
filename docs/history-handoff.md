# История и аудит

Перемещения доступны лаборанту и администратору, общий журнал действий — только администратору. Преподавателю эти разделы недоступны.

- Перемещения: `/app/movements`, API `/api/movements`.
- Журнал: `/app/audit`, API `/api/audit`.

Есть поиск, фильтры, страницы, RU/EN и темы. Данные берутся из PostgreSQL. Перемещение записывается при смене аудитории в карточке оборудования.

Запуск описан в [README](../README.md), устройство — в [архитектуре](architecture.md), проверки — в [общем отчёте](testing-report.md).
