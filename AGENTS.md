# Работа над проектом

- Не добавлять комментарии в исходный код, тесты и конфигурационные файлы. Пояснения размещать в Markdown-документации.
- Использовать понятные названия и небольшие функции; избегать лишних зависимостей и абстракций.
- Самир отвечает за frontend/, общий Compose, CI и деплой. Артём отвечает за backend/, схему БД и миграции.
- Не менять чужую часть без согласования. Контракт API согласуется через docs/ и PR.
- Работать в feature-ветках, не отправлять код напрямую в main. PR проверяет второй участник.
- Не выдавать демонстрационный frontend за готовое fullstack-приложение. Не заявлять о проверках, которые не выполнялись.
- Не коммитить секреты, .env, node_modules, загруженные пользователями файлы и отчёты с личными данными.
