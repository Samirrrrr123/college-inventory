# Инвентарь

Веб-приложение для учёта оборудования и аудиторий колледжа.

[Открыть приложение](https://85.8.201.148/login) · [Swagger / OpenAPI 3](https://85.8.201.148/api/docs/)

## Возможности

Есть регистрация, вход, восстановление пароля, профиль и история действий. Три роли — преподаватель, лаборант и администратор; доступ проверяет сервер.

Можно вести каталог оборудования, категории и аудитории, искать и фильтровать записи. Преподаватель подаёт заявки, сотрудники одобряют их, выдают технику и принимают возвраты. Операция с комплектом сохраняется целиком. Перемещения оборудования записываются в историю. В карточку можно добавлять PNG, JPG и PDF до 5 МБ, скачивать и удалять их по правам.

Лаборант проводит инвентаризацию по аудитории: отмечает наличие, завершает проверку и смотрит результат в истории. Состав оборудования фиксируется при начале, готовые результаты не редактируются.

Администратор меняет роли, блокирует и разблокирует пользователей. Изменение доступа закрывает старые сессии. Последнего активного администратора нельзя отключить.

Есть мобильная версия, светлая и тёмная темы, RU/EN. Данные сохраняются в PostgreSQL. Backend предоставляет статистику, общий аудит, историю перемещений и экспорт XLSX. Подключение новых API к соответствующим страницам интерфейса описано в [передаче backend](docs/backend-completion.md); демонстрационные страницы сами по себе не подтверждают эту интеграцию.

## Стек и участники

React, TypeScript strict, Vite, React Router, Tailwind CSS; Node.js, Express, Prisma, PostgreSQL. Запуск — Docker Compose; CI — GitHub Actions. Тесты — Vitest, Testing Library, Supertest и Playwright.

- **Самир:** дизайн, frontend, интеграция, тесты интерфейса, CI, развёртывание; модули аккаунтов, заявок, выдач и возвратов.
- **Артём:** backend предметной области, схема БД и миграции, API каталога и серверные тесты.

## Запуск

Нужны Docker с Compose и Node.js 24. Из корня репозитория:

```sh
node scripts/setup-env.mjs
docker compose up --build
```

Приложение: http://127.0.0.1:8080/login. Swagger: http://127.0.0.1:8080/api/docs/.

Тестовые аккаунты: `admin@college.test`, `technician@college.test`, `teacher@college.test`. Пароль берётся из `SEED_PASSWORD` в локальном `.env`; повторный seed сохраняет существующие пароли и записи. Регистрация создаёт преподавателя. Ссылка восстановления пароля выводится в журнал backend. База хранится в Docker volume; секреты не включаются в репозиторий.

| Оперативная память     | 2 ГБ                                                                   |
| Диск                   | 40 ГБ                                                                  |
| ОС                     | Ubuntu 24.04.4 LTS, x86_64                                             |
| Публичный IPv4         | 85.8.201.148                                                           |
| Адрес приложения       | https://85.8.201.148/login                                             |
| Каталог проекта на VPS | `/opt/college-inventory`                                               |

Отдельного домена нет: сайт работает по IP с HTTPS. Сертификат Let’s Encrypt продлевает Caddy. В Docker работают Caddy, frontend с Nginx, backend и PostgreSQL. База закрыта от прямого доступа из интернета. SSH использует ключ; секреты находятся в `.env`, копии базы — в `/var/backups/college-inventory`.

При первом запуске на VPS создать `.env` командой выше и задать в нём `PUBLIC_HOST`. Для обновления сначала сохранить копию БД, затем выполнить в каталоге проекта:

```sh
git pull --ff-only origin main
docker compose -f compose.yaml -f compose.production.yaml up --build --detach --wait
```
