# Инвентарь

Веб-приложение для учёта оборудования и аудиторий колледжа.

[Открыть приложение](https://85.8.201.148/login) · [Swagger / OpenAPI 3](https://85.8.201.148/api/docs/)

## Возможности

Работают регистрация, вход, восстановление и смена пароля, профиль и история аккаунта. JWT-сессии используют access-токен и refresh-cookie. Три роли — преподаватель, лаборант и администратор; права проверяются на сервере.

Каталог оборудования, категории и аудитории поддерживают CRUD, серверные поиск, фильтры, сортировку и пагинацию. Преподаватель создаёт заявки и видит свои записи; сотрудники рассматривают заявки, выдают оборудование и принимают возвраты. Выдача и возврат всего комплекта сохраняются одной транзакцией. Изменение аудитории оборудования записывает перемещение.

Интерфейс адаптивный, со светлой и тёмной темами и языками RU/EN. Данные рабочих разделов сохраняются в PostgreSQL. Инвентаризация, административное изменение пользователей, загрузка файлов, статистика БД, общий журнал аудита и XLSX пока не подключены к рабочему приложению; отдельная демоверсия не заменяет эти функции.

## Стек и участники

React, TypeScript strict, Vite, React Router, Tailwind CSS; Node.js, Express, Prisma, PostgreSQL. Запуск — Docker Compose; CI — GitHub Actions. Тесты — Vitest, Testing Library, Supertest и Playwright.

- **Самир:** дизайн, frontend, интеграция, тесты интерфейса, CI, развёртывание; модули аккаунтов, заявок, выдач и возвратов.
- **Артём:** backend предметной области, схема БД и миграции, API каталога и серверные тесты.

## Запуск

Нужны Docker с Compose и Node.js 24. Из корня репозитория:

```sh
node scripts/setup-env.mjs
docker compose up --build
```

Приложение: http://127.0.0.1:8080/login. Swagger: http://127.0.0.1:8080/api/docs/.

Тестовые аккаунты: `admin@college.test`, `technician@college.test`, `teacher@college.test`. Пароль берётся из `SEED_PASSWORD` в локальном `.env`; повторный seed сохраняет существующие пароли и записи. Регистрация создаёт преподавателя. Ссылка восстановления пароля выводится в журнал backend. База хранится в Docker volume; секреты не включаются в репозиторий.

| Каталог проекта на VPS | `/opt/college-inventory`                                               |

Стоимость указана по заказу от 20.10.2026. Отдельный домен не приобретался. Caddy получает и автоматически продлевает сертификат Let’s Encrypt для IP; HTTP перенаправляется на HTTPS. Приложение запускается четырьмя контейнерами: Caddy, Nginx с frontend, backend и PostgreSQL. База и backend напрямую в интернет не публикуются. Открыты SSH и HTTP/HTTPS; SSH использует ключ. Секреты хранятся в серверном `.env`, резервные копии БД — в `/var/backups/college-inventory`.

Для первого развёртывания создать `.env` командой `node scripts/setup-env.mjs`, задать в нём `PUBLIC_HOST` и выполнить команду Compose ниже. На уже настроенном VPS обновление выполняется из каталога проекта после резервного копирования БД:

```sh
git pull --ff-only origin main
docker compose -f compose.yaml -f compose.production.yaml up --build --detach --wait
```
